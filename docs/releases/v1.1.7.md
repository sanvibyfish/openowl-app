# openOwl v1.1.7 Release Notes

> **Status**: 🟢 Ready | **Notes Ready**: 2026-08-30 | **Released**: —

Live multi-agent visibility and a file explorer display fix.

**Teammates** — a new right-dock tab — watches the agent sessions running around
you and attaches to them in one click:

- **Claude** Team/swarm sessions (`View teammates: tmux -L claude-swarm-<pid> a`)
  with per-agent color/role/model (resolved deterministically through the tmux
  pane's process) and a live output tail. Attach runs `tmux -L <socket> a` in a
  new terminal tab.
- **Codex** sessions from the local session index, attach via `codex resume`.
- **Pi** sessions from the transcript store — the conversation running pi
  right now shows up as a live entry; attach opens the transcript in the editor.

## New Features

### Teammates panel (FEAT-012)

- Right Dock gains a **Teammates** tab (list-only width), polling every 5s, one
  card per live/recent session with a source badge (Claude / Codex / Pi), agent
  rows, and a live tail preview.
- Claude swarm discovery reads the user's tmux sockets
  (`/private/tmp/tmux-<uid>/claude-swarm-*`), probes liveness with
  `tmux -L <s> ls`, and maps each pane to its agent via `pane_pid` → `ps` —
  no fragile pane-title matching. `capture-pane` feeds the live tail.
- Codex discovery reads `~/.codex/session_index.jsonl` (most recent sessions)
  and enriches cwd from the matching archived rollout; attach is
  `codex resume <id>`.
- Pi discovery reads `~/.pi/agent/sessions/**/*.jsonl` (most recent transcripts);
  the session header yields project, model and first-message title. Attach opens
  the transcript in the editor.
- Attach for terminal-based sources opens a new terminal tab and collapses the
  dock so the agent is actually visible; file-based attach opens the editor.

## Bug Fixes

### File explorer rows no longer clipped from the left

- Selecting a deeply-indented file made AppKit's `scrollRowToVisible` pan the
  outline's clip view horizontally to reveal the overflowing cell, shoving every
  shallower row left so leading glyphs and icons disappeared behind the panel
  edge. A `TreeClipView` now pins the horizontal scroll origin to 0 — a file
  tree truncates names and never pans sideways.
- The outline column also stopped tracking the panel width, leaving a dead
  strip on the right (`sizeLastColumnToFit` runs once, `autoresizesOutlineColumn`
  is off by design). The column is now re-pinned to the outline view's real
  width on layout, change-guarded.
