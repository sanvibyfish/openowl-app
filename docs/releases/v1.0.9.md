# openOwl v1.0.9 Release Notes

**Release Date**: 2026-05-30

Bug fixes for terminal tab jumping and file editor notification timing, plus a file-based logging system for production diagnostics.

---

## Bug Fixes

### Independent terminal tab kept jumping back to first tab

When the user selected a non-first tab in a free-terminal namespace, every shell command triggered OSC 7 pwd reporting → `syncActiveProjectContext` → `switchNamespace`, which unconditionally reset `activeTabID` to the first tab. Typing in a second or third terminal tab was impossible — the selection snapped back on every keystroke.

**Fix:** `TerminalWorkspaceStore.switchNamespace` now checks whether `activeTabID` already belongs to the target namespace. If it does, the method returns immediately, preserving the user's tab selection. Cross-namespace switches still reset to the first tab as expected.

**Tests:** `switchNamespace_sameNamespace_preservesActiveTab` and `switchNamespace_differentNamespace_resetsToFirstTab`.

### Opening a file from terminal failed when dock was collapsed

When the right dock was collapsed (or showing a different tab like Git), clicking a file link in the terminal triggered `rightDockStore.expand(tab: .files)` followed by a synchronous `NotificationCenter.post(.openFileFromTerminal)`. But `FileExplorerView` is conditionally mounted by `ContentView` — when the dock was collapsed, the view (and its `onReceive` subscriber) didn't exist yet. The notification was posted into the void.

**Fix:** `openOwlApp.openFileURL` now defers the notification by one runloop tick (`DispatchQueue.main.async`) when the dock was not already showing the Files tab. This gives SwiftUI time to mount `FileExplorerView` and register its subscriber before the notification arrives. When the dock was already showing Files, the notification posts synchronously (no delay needed).

## New Feature

### File-based logging system (AppLogger)

All diagnostic logs now write to `~/Library/Logs/openOwl/openowl.log` in addition to `NSLog`. This makes logs accessible on packaged production builds without needing Xcode or Console.app.

- **Location:** `~/Library/Logs/openOwl/openowl.log`
- **Rotation:** 10 MB cap, auto-rotates to `openowl.1.log` (max 1 old file)
- **Thread-safe:** serial `DispatchQueue` with `.utility` QoS
- **Dual output:** `NSLog` (dev console) + file (production)

See `docs/features/009-app-logger.md` for full documentation.
