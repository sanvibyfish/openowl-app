# openOwl v1.1.6 Release Notes

> **Status**: 🟢 Ready | **Release Date**: 2026-08-17

> **2026-08-18 更新**：本版本中的消息总线功能（分屏 pane 命名 / `openowl bus-send` 路由）已随 [REQ-009](./requirements/REQ-009-message-bus.md) 整体删除，不再存在于当前代码库。本节保留为已发布版本的档案记录。

Terminal message-bus naming and Git panel reliability release. v1.1.6 adds a naming entry point for split panes on the message bus, fixes the Git panel's "Bad file descriptor" failure mode that left the changes list stuck on a stale snapshot, and hardens the Git child-process pipeline with automatic retry and diagnostics.

---

## New Feature

### Name split panes on the message bus (REQ-009)

Project split-pane terminals can now be addressed by a human-readable name, matching the free-terminal tab-pill entry point:

- Right-click a split pane's three-dot handle → **Set Message Bus Name…** → enter a name like `codex-a` or `pi-main`.
- The name becomes the pane's bus address immediately — `openowl bus-send <name> "…"` routes to that pane.
- Hovering the handle shows the current bus name in the tooltip; **Clear Message Bus Name** removes it.
- Works on maximized panes too. Overrides are per-pane-UUID and session-scoped (re-set after relaunch, as before).

## Bug Fixes

### Git panel no longer stuck on "Bad file descriptor"

- The Git panel could show a stale snapshot plus `The operation couldn't be completed. Bad file descriptor` — an EBADF from the git child's pipe/posix_spawn setup under the app's fd churn (terminal PTY activity). The error was never logged, so the panel stayed broken silently.
- Child-launch failures (EBADF/EMFILE/ENFILE/EAGAIN) now retry once with fresh pipes — safe, because the child never runs on a failed launch. Refreshes recover instead of parking on the old snapshot.
- All Git child failures are now written to the `[git]` app log with the command and error detail; pipe dup failures log the fd and errno.
- `GitPipeDrain` close is now idempotent across `finish()` / timeout / `deinit` paths, eliminating double-close of the dup'd descriptor.

### Terminal surface failure shows an in-place notice

- If a ghostty surface fails to initialize, the pane now renders a clear centered error notice instead of failing silently into a blank view.

### Message-bus ID timestamps are timezone-safe

- `buslib.py` message IDs and heartbeat age computation now use UTC datetime instead of local-time `gmtime` string formatting, keeping message ordering and online/offline windows correct regardless of system timezone.
